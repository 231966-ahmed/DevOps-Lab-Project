# CIC-IoT2023 Network Intrusion Detection

## Project Description

This project focuses on network intrusion detection using machine learning techniques and the CIC-IoT2023 dataset.

The main objective is to analyze network traffic and classify it to identify potentially malicious activities.

## Dataset

**Dataset:** CIC-IoT2023

The dataset contains network traffic records used for machine learning-based intrusion detection.

Dataset source: https://www.unb.ca/cic/datasets/iotdataset-2023.html

The dataset files are not included in this repository because of their size. Download and configure the dataset separately.

## Project Workflow

- Dataset loading
- Data preprocessing
- Exploratory data analysis
- Feature selection and preparation
- Training and testing machine learning models
- Model evaluation
- Performance comparison

## Evaluation Metrics

Depending on the classification task, the project may evaluate:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Project Files

- `CIC-IoT2023-Classification.ipynb` — Main machine learning notebook.
- `README.md` — Project documentation.
- `requirements.txt` — Python dependencies.
- `.gitignore` — Files excluded from Git tracking.

## How to Run

1. Install Python or open Google Colab.
2. Install the required dependencies.
3. Download the CIC-IoT2023 dataset.
4. Configure the dataset path in the notebook.
5. Open and execute the notebook cells.
